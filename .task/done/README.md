# Archive

Completed tasks are stored here as subdirectories.

## Naming convention

    {id}-{short-name}/

Example: `001-add-dark-mode/`

Each subdirectory contains the full task workspace snapshot:
- `overview.md`
- `context.md`
- `plan.md`
- `implementation.md`
- `followups.md`
- `design/` (folder, if it exists and has files)
