# Lean Mode

No pre-built codebase context is provided for this task — a FILE TREE
section follows instead of file summaries. Before producing a plan,
first reply with a short numbered list (at most 15) of the file paths
from that tree you need to read in full, and wait — do not produce the
plan yet. If the task involves behavior or business-logic changes,
include one existing test file from the tree in that list, so test steps
can name real paths and follow the project's test conventions.

The human will run `bin/attach.sh <paths>` and attach those files in a
follow-up message. Only then produce the plan in the format above.
